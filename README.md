# X Post2Image

Chrome 扩展：在 X / Twitter 的原生分享菜单里把帖子复制成截图。截图尽量保留页面上的真实样式，可改评论、转发、点赞、收藏、曝光。

非官方工具，与 X Corp. 无关。图上的互动数据可以编辑，不能当作真实数据证据。

## 功能

- 点帖子分享按钮，菜单顶部出现「复制成推文截图」
- 弹出预览，数字改完立刻反映在卡片上
- 自动去掉 X 爆款监测等插件叠在帖子上的流速角标
- 复制 PNG 到剪贴板，或下载文件
- 全程在本地生成，帖子内容不会上传

## 安装

1. 安装依赖并构建：

```bash
npm install
npm run build
```

2. 打开 `chrome://extensions/`
3. 打开「开发者模式」
4. 点「加载已解压的扩展程序」，选择本仓库的 `dist/` 目录
5. 刷新已经打开的 x.com 页面

开发时可用 `npm run dev` 监听源码变化，改完后在扩展页点重新加载。

## 使用

1. 打开任意帖子或时间线卡片
2. 点分享
3. 选「复制成推文截图」（英文界面是 Copy as screenshot）
4. 按需改评论、转发、点赞、收藏、曝光
5. 点「复制图片」后即可粘贴

## 限制

- X 改版后分享菜单选择器可能失效，需要再适配
- 视频一般只能留下封面
